# Devil

**Devil** is an action-RPG built on top of [OpenDiablo2](https://github.com/OpenDiablo2/OpenDiablo2), an open-source, GPLv3 ARPG engine written in Go (clean-room reimplementation of Diablo 2's engine — no Blizzard assets or code included).

See:
- [`ROADMAP.md`](./ROADMAP.md) — engine/implementation roadmap
- [`devil_lore.md`](./devil_lore.md) — story and lore
- [`devil_game_design_reference.md`](./devil_game_design_reference.md) — game design reference
- [`devil_mage_character_design.md`](./devil_mage_character_design.md) — character design

> This project does not ship with the assets or content required to play Diablo 2. Running the underlying engine against the original game requires a legally purchased copy of [Diablo 2](https://us.shop.battle.net/en-us/product/diablo-ii) and its expansion [Lord of Destruction](https://us.shop.battle.net/en-us/product/diablo-ii-lord-of-destruction).
